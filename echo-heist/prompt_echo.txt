## PATCH

Title:
PATCH//RUN

Hook:
Every 20 seconds a permanent patch changes one rule of the arena. Patches stack and create increasingly chaotic interactions.

Core experience:
Top-down arena action.

Controls:
WASD movement
mouse aim
left click shoot
Space dash

Gate 1 MUST contain:

* player movement
* aiming
* shooting
* exactly one enemy archetype
* enemy pursues player
* player health
* damage
* death
* restart
* patch countdown visible on screen
* exactly 3 prototype patches
* patch effects permanently stack during the run
* at least one visible interaction between two active patches

Use these EXACT three prototype patches:

1. RICOCHET
   Player bullets bounce off arena walls once.

2. GROWTH
   Each time a player bullet bounces, its visual size and damage increase.

3. FRIENDLY FIRE
   Player bullets that bounce can also damage enemies they subsequently hit normally; ensure the RICOCHET + GROWTH interaction is visually obvious.

For Gate 1, apply the three patches automatically in this fixed order every 20 seconds:

20 sec → RICOCHET
40 sec → GROWTH
60 sec → FRIENDLY FIRE

Show a large PATCH notification when each activates.

Do not implement random patch selection yet.

Gate 1 PASS criteria:

* game launches
* player movement feels responsive
* player can aim and shoot
* enemies can kill player
* player can kill enemies
* timer visibly reaches patch events
* all three patches activate
* RICOCHET + GROWTH interaction is obvious
* death screen appears
* restart begins a clean new run

## ECHO

Title:
ECHO HEIST

Hook:
Every loop records your actions. On the next loop, your previous self repeats those actions and can help the current player.

Core experience:
Compact time-loop puzzle/action game.

Controls:
WASD movement
E interaction

Gate 1 MUST contain:

* player movement
* one room
* one pressure switch
* one locked door
* one goal zone behind the door
* fixed 20-second loop
* record player movement/actions during loop
* replay previous loop as visible ghost
* ghost can activate the pressure switch
* current player can walk through door while ghost holds switch
* loop reset
* full restart

Do NOT add enemies yet.
Do NOT add a second ghost yet.
Do NOT add multiple rooms.

Required Gate 1 puzzle:

Loop 1:
Player walks onto switch near the left side of room and remains there until loop ends.

Loop 2:
Ghost repeats Loop 1 and holds switch.
Door opens.
Current player walks through door and reaches goal.

Gate 1 PASS criteria:

* loop timer is visible
* recording begins automatically
* loop resets correctly
* previous player appears as ghost
* ghost follows recorded path reliably
* ghost triggers switch
* door responds correctly
* current player reaches previously inaccessible goal
* restart completely clears recording state

Prioritize deterministic reliable replay over visual quality.

## BOSS

Title:
BOSS FORGE

Hook:
You choose the boss's attacks yourself, then immediately have to survive the boss you created.

Core experience:
Short boss configuration followed by boss fight.

Controls:
WASD movement
mouse aim
left click attack
Space dodge

Gate 1 MUST contain:

PHASE 1:
Boss configuration screen.

Provide exactly three selectable attack modules:

1. RADIAL BURST
   Boss fires 8 projectiles in all directions.

2. AIMED SHOT
   Boss fires a projectile toward current player position.

3. ROTATING BEAM
   Boss emits a clearly telegraphed rotating beam attack.

Player must choose exactly TWO modules.

PHASE 2:
Fight.

Boss uses only the two modules selected by player.

Include:

* player movement
* player attack
* dodge
* player health
* boss health
* clear attack telegraphs
* win
* death
* restart
* return to configuration

Different module selections must produce noticeably different fights.

Gate 1 PASS criteria:

* configuration screen works
* exactly two modules can be selected
* fight starts
* boss uses selected modules only
* attacks are readable
* player can damage boss
* player can die
* boss can die
* win/lose screen appears
* restart returns to configuration
