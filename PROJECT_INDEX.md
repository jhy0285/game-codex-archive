## Shared documentation convention

Most developed games contain:

- `GAME.md`: gameplay contract and design intent.
- `progress.md`: chronological implementation history.
- `TASKS.md`: completed and remaining tasks.
- `TEST.md`: test evidence and commands.
- `CODEX_LOG.md`: agent work log.
- `ASSET_CREDITS.md`: image prompts, processing, licensing, and provenance.
- `PLAYTEST.md`: human-testing checklist or results.

Do not delete these as generated clutter. They are part of the Codex handoff context.
